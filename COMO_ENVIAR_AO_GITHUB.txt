COMO ENVIAR AO GITHUB
1. Extraia o ZIP.
2. No repositório SuperMercado-Vierira, use Add file > Upload files.
3. Envie o conteúdo extraído mantendo a estrutura da raiz e confirme o commit.
4. Aguarde o deploy do Vercel, se conectado ao repositório, e atualize com Ctrl+F5.
